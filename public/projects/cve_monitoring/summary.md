# HPC Security Vulnerability Assessment (CVEs)

The goal was to develop a process to handle the influx of CVEs being discovered by being able to quickly identify which ones affect an HPC Environment so we can quickly mitigate threats.

## What Was Done

A script developed that collated multiple security sources and compared against provided package versions from an HPC Environment.

## What Was Learnt

AI-enhanced development techniques allow for the rapid evolution of a solution and aid in prioritising.
