# Cluster Visualisation

The goal was to provide users with an alternative to mundane dashboards, offering a more accessible and engaging way to visualise their cluster.

## What was done

We developed interactive 3D visualisations of clusters in the browser using TypeScript and Three.js. API calls were made to a backend that provided information about the cluster, which was then modelled by the frontend and displayed to the user.

## What was learnt

This project demonstrated that visualisation tools do not have to follow the standard, somewhat boring dashboard format, and that users may actually benefit from a more engaging 3D experience. This approach has the potential to make the otherwise mundane process of monitoring and checking clusters more intuitive, accessible and enjoyable for end users.
