# Hackathon 13
The goal was to explore how user experience engineering can make learning new technologies easier and more accessible through self-guided, progressive learning experiences.
# What was done
Three teams developed different learning experiences:
- **Team 1:** A CLI-based tutorial for learning SLURM
- **Team 2:** A gamified 2D platformer for learning virtual machine provisioning.
- **Team 3:** A troubleshooting challenge highlighting the importance of clear and accurate documentation.
# What was learnt
We learnt that effective user experiences go beyond good documentation, requiring clear guidance, hands-on interaction and progressive challenges to help users build confidence when learning new technologies.
