# Flight Solo

The goal was to create a platform-agnostic HPC image that enables users to quickly deploy complete, ready-to-use HPC environments across different cloud platforms.

# What was done

Developed Flight Solo using an HPC-optimised Rocky Linux 9 image, Cloud-Init and the preconfigured Flight Environment. Supported deployment across OpenStack, AWS and Azure, with the image also made available through the AWS Marketplace.

# What was learnt

Learned how preconfigured cloud images and runtime configuration can simplify HPC deployment. Demonstrated how a consistent, reusable image can make HPC environments quicker to provision and more accessible to researchers.
