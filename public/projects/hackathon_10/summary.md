# Hackathon 10

The goal was to explore project adoption and different testing approaches, using user personas and AI to uncover bugs, usability issues and gaps in project specifications.

# What was done

Existing projects were revisited and adopted by different participants. Projects were made functional again where necessary, with changes documented alongside newly written specifications. We then used different testing personas to identify technical bugs and documentation gaps before using AI to expand testing coverage and explore additional improvements.

# What was learnt

We learnt how different user perspectives can expose overlooked bugs and usability issues, and how AI can complement manual testing to improve software quality and expand test coverage.
