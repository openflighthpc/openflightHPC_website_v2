# Hackathon 4

The goal was to use generative AI to create unique mascots representing HPC clusters, using their technical attributes and surrounding environment.

# What was done

We developed an image generation server and Next.js UI for creating mascots. Generated statistics based on HPC and environmental data, displayed mascots as Top Trumps-style cards, and created a CLI battling game where mascots competed using their stats.

# What was learnt

We learnt how to host and integrate AI image generation models, build connected frontend and backend services, work with external APIs, and turn real-world data into interactive game mechanics.
