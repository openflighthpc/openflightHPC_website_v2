# HPC End User Basics

The goal was to create documentation introducing users to the fundamental concepts and skills needed to work effectively in an HPC environment, from basic command-line usage to workload management and administration.

# What was done

We created guides covering HPC environment basics, CLI skills, data management and Slurm usage. Also documented Genders and PDSH, explaining how to organise compute nodes into groups and execute commands across multiple hosts.

# What was learnt

We learnt the importance of clear, accessible documentation in helping users navigate HPC environments. Explored how tools such as Genders and PDSH simplify cluster administration and bulk host management.
