# Flight Environment

The goal was to assemble a collection of tools for HPC environment accessibility and management, bringing together user-facing and administrator tools into one system.

# What was done

We created the Flight Environment across three components: a User Suite with CLI tools for desktop sessions, software ecosystems, object storage and job handling; a Web Suite providing browser-based access to terminals, desktops and files; and Admin Tools for cluster configuration, system inventory and host profile management. The tools work independently but become more powerful together.

# What was learnt

We learnt how to design self-service tools that reduce administrator workload, integrate user and admin tooling around a common shell entrypoint, and document end-to-end workflows from cluster setup through to daily use across gather, hunter, profile, desktop, env and silo.
