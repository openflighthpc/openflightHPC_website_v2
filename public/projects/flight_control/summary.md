# Flight Control

The goal was to build a Ruby on Rails application for monitoring cloud costs and managing AWS and Azure instances, helping organisations control spending and reduce resource waste.

# What was done

We developed Flight Control with cost-tracking dashboards, instance lifecycle management, budget policies and idle-node detection. Integrated Slack, Flight SSO, role-based permissions, scheduled tasks, background processing and audit logging.

# What was learnt

We explored how cloud cost monitoring, automation and instance management can work together to improve resource efficiency. Learned the value of integrating multiple cloud providers into a centralised management platform.
