# Hackathon 9

The goal was to explore OpenTUI, a framework for building interactive graphical interfaces within the terminal, and experiment with creating applications that go beyond traditional CLI functionality.

# What was done

We developed several small, complete projects using OpenTUI, including a clicker game, a visual interface for TAC, a 3D Solar System visualiser, a 1v1 shooter, Minesweeper and a multimedia album browser.

# What was learnt

We learnt how to use OpenTUI alongside technologies such as React and Three.js, exploring how terminal applications can support interactive graphics, games, 3D visualisations and multimedia experiences.
